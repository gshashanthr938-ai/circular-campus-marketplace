# Generated product photographs

The 16 images in `src/main/webapp/img/generated/` were created for this academic project with OpenAI's built-in image generation tool on 21 September 2026. They are local project assets, so listing cards do not depend on third-party product URLs.

Each prompt requested realistic, unbranded, second-hand product photography for a specific campus item. The common composition was a centered item, landscape 4:3 framing, a neutral student-room or tabletop background, soft daylight, no people, no logo, no watermark, no text and no unrelated products.

Generated subjects: wired studio headphones, Bluetooth headphones, paperback reading bundle, engineering reference books, fiction books, graphite pencils, colour pencils, sketchbook with drawing pencils, semester planner, weekend backpack, basketball, data-structures textbook, student calculator, foldable study table, adjustable LED lamp and engineering drawing kit.
