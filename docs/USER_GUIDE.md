# CampusMarket User Guide

CampusMarket is a student-to-student marketplace for buying and selling second-hand campus products.

## 1. Registration and Login

1. Open CampusMarket.
2. Select **Sign up**.
3. Enter your name, email address, phone number and password.
4. Select **Create account**.
5. Existing users can select **Login** and enter their email and password.
6. No wallet money is provided during registration.

## 2. Browsing and Searching

1. Open the **Browse** page.
2. Enter a product name in the search field.
3. Select a category such as Books, Electronics, Stationery or Furniture.
4. Enter a maximum price if required.
5. Select **Filter**.
6. Open a product to view its photographs, condition, price, seller information and reviews.

## 3. Adding Products to the Cart

1. Select the **+** or **Add to cart** button.
2. Guests can add items before logging in.
3. The guest cart is stored using a browser cookie.
4. After login, valid guest-cart items automatically move to the logged-in cart.
5. A student cannot purchase their own listing.

## 4. UPI and Net-Banking Checkout

1. Open the cart.
2. Review the product, seller and total price.
3. Choose **UPI** or **Net banking**.
4. For UPI, enter a valid-looking UPI ID such as `student@bank`.
5. For net banking, select a bank.
6. Read the purchase terms.
7. Select the terms-acceptance checkbox.
8. Select **Confirm payment and place order**.
9. The order history displays the payment method and transaction reference.

CampusMarket uses an academic payment simulation. It does not collect bank passwords, account numbers or OTPs.

## 5. Selling a Product

1. Log in and select **Sell**.
2. Enter the product title and description.
3. Choose the category and condition.
4. Enter a reasonable selling price.
5. Upload between one and three photographs of the actual product.
6. Supported image formats are JPG, PNG and WebP.
7. Each image must be no larger than 3 MB.
8. Select **Publish listing**.

CampusMarket rejects prohibited products such as cigarettes, vapes, alcohol, weapons, narcotics and fireworks. It also checks for unusually high prices.

## 6. Pickup-Code Confirmation

1. After checkout, the buyer opens **History**.
2. The buyer can see the seller’s contact details and a private six-digit pickup code.
3. The buyer and seller meet on campus.
4. The buyer inspects the product.
5. After receiving the product, the buyer shares the pickup code with the seller.
6. The seller opens **History → My Sales**.
7. The seller enters the six-digit code and selects **Confirm pickup**.
8. The transaction changes to **Delivery confirmed**.
9. The buyer can then submit a verified rating and review.
